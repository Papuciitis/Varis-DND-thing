# Creature names

69 reviewed title overrides give reusable encounter names while retaining stable IDs and numerical profiles. The manual contains 302 creatures. Titles identify species, anatomy, role or equipment, without personal or gender labels.

The reviewed overrides live in `data/monsters/custom.yaml`; `data/monsters/source/generic-name-index.json` records their immutable targets. Existing imports and archived numerical facts remain traceable. Summon references use the current titles.

Older browser edits adopt current default titles and collection paths while retaining HP changes and other edits. Deliberately chosen custom names remain unchanged. Editor exports preserve the overrides and current targets.
